## 🚀 Client & production projects

> Real products, deployed and running in production.

### 🌿 [Vademecum IA](https://www.vademecumia.com/) — Agri-tech AI Assistant
WhatsApp-native AI assistant for the agricultural sector. Farmers and field technicians query Spain's official MAPAMA phytosanitary database using plain language — getting instant answers on products, pests, crops, and safety deadlines. Built with a **multi-agent RAG architecture** combining vector retrieval, fuzzy string correction, and a conversational WhatsApp interface. Database updated every Monday automatically.

`LangGraph` `RAG` `Fuzzy Matching` `WhatsApp API` `Vector DB` `Python`

---

### 🏦 Enterprise AI @ AXA
Two complementary systems deployed on **Microsoft Azure** for the AXA corporate environment:
- **Synthetic dataset generation** using NVIDIA Nemotron + encoder models — enabling safe RAG benchmarking without touching sensitive real data.
- **Massive PDF RAG system** — bulk ingestion, versioned vector storage, and reliable retrieval over thousands of corporate documents in a regulated environment.

`Azure` `NVIDIA Nemotron` `Qdrant` `PDF Ingestion` `Enterprise RAG`

---

### 🎓 Academic RAG @ Universitat Politècnica de València
End-to-end RAG system indexing **20+ years of academic publications** for the UPV research community. Full ownership from raw document ingestion to the user-facing interface. Researchers query the entire historical corpus in seconds via natural language.

`RAG` `Vector DB` `Full-stack` `Python` `Semantic Search`

---

### 📑 Tender Analysis Pipeline
Multi-agent pipeline processing **100–300 PDFs simultaneously** — tender requirements, supplier offers, and attached documents — automatically scoring and ranking providers with detailed justifications.

> ⚡ **4 days of human work → ~10 minutes**

`Parallel Agents` `PDF Processing` `Azure` `Multi-agent` `Scoring Pipeline`

## 📦 Open source & community repos

### ⚡ [Real-Time Voice Agent — Community Edition](https://github.com/damiangilgonzalez1995/real-time-comunidad)
Created for **my community of non-technical learners**. A step-by-step resource explaining how real-time audio systems work — from digital audio fundamentals to Voice Activity Detection (VAD), Speech-to-Text, and full streaming AI pipelines. Zero assumptions, beginner-friendly notebooks.

`FastRTC` `VAD` `Moonshine STT` `Python` `Jupyter` `Community`

---

### 🏭 [Agent Factory Helper](https://github.com/damiangilgonzalez1995/agent-factory-helper)
When you build complex multi-agent networks professionally, you need patterns that scale. This project provides architectural scaffolding and helper utilities for designing **production-grade agent networks** — born from real client engagements where agent topology matters.

`LangGraph` `Multi-agent Architecture` `Python` `Design Patterns`

---

### 🔬 [Finetuning Library](https://github.com/damiangilgonzalez1995/finetunning-library)
A practical, theory-grounded library for fine-tuning LLMs. Covers how fine-tuning really works under the hood — from data pipelines to training loops — with reproducible, production-ready code.

`HuggingFace` `PEFT` `LoRA` `Python` `LLM Training`

---

### 📊 [Clustering with LLM](https://github.com/damiangilgonzalez1995/Clustering-with-LLM) ⭐ Popular
Advanced customer segmentation using LLMs. Goes beyond traditional clustering by using language models to **define, interpret, and narrate** clusters — making results explainable to non-technical stakeholders.

`Python` `LLMs` `Clustering` `Customer Segmentation` `Explainability`

---

### 🔍 [Advanced Retrieval RAGs](https://github.com/damiangilgonzalez1995/AdvancedRetrievalRags)
Deep dive into advanced RAG retrieval strategies — query decomposition, reranking, hybrid search, and more. A reference repo for building retrieval systems that actually perform in production.

`RAG` `LangChain` `Retrieval` `Vector Search` `Python`
